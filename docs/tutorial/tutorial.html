Consultório VR — Guia rápido

APK no Quest (PC de casa) + servidor dedicado no Linux (servidorNetuno) · Unity 6000.0.39f1
[Quest com APK] --Ethernet--> [Roteador 5G] --5G--> [Core 5G] --cabo--> [servidorNetuno: ConsultorioServer, UDP 7777]
  • Quest: roda o cenário e conecta sozinho no IP do servidor (172.30.22.31). Se a conexão falhar ou cair, tenta de novo a cada 3 s.
  • Servidor Linux: roda o mesmo cenário sem gráficos, como servidor (host da sala). Não precisa configurar IP.
  • Ordem: servidor rodando → abrir o app nos óculos.

1. PC de casa — gerar e instalar o APK

1.1 Atualizar o projeto

cd E:\testeMultiplayer3.0
git switch main
git pull
git lfs pull

1.2 Gerar o APK

  1. Abra o projeto no Unity 6000.0.39f1.
  2. Abra Assets/Scenes/ConsultorioFinal.unity e confira no objeto com Lan Direct Connect: Host Ip Address = 172.30.22.31.
  3. Menu Build → APK Meta Quest (Android). Saída: Builds\Android\ConsultorioVR.apk.

1.3 Instalar no Quest (modo desenvolvedor já ativo)

Quest no USB, aceite "Permitir depuração USB" no headset:

adb devices
adb install -r Builds\Android\ConsultorioVR.apk
adb tcpip 5555

Ou use File → Build Profiles → Android → Build And Run.

1.4 Plano B — build do servidor no Windows

Caso a licença do Unity não ative no servidor (passo 2.4), gere aqui: menu Build → Servidor Linux (Dedicated Server). Precisa do módulo Linux Dedicated Server Build Support no Unity Hub. Envie no lab com:

scp -r .\Builds\LinuxServer admin@172.30.22.31:~/consultorio-build

E pule para o passo 2.7.

2. Servidor Linux (via SSH)

ssh admin@172.30.22.31

2.1 Dependências

sudo apt update
sudo apt install -y git git-lfs tmux wget xz-utils libgtk-3-0 libnss3 libasound2t64 libgbm1 xvfb
git lfs install

2.2 Unity Editor (download direto)

mkdir -p ~/Unity/6000.0.39f1 && cd ~/Unity/6000.0.39f1
wget https://download.unity3d.com/download_unity/15ea7ed0b100/LinuxEditorInstaller/Unity-6000.0.39f1.tar.xz
tar -xf Unity-6000.0.39f1.tar.xz
rm Unity-6000.0.39f1.tar.xz
ls Editor/Unity

2.3 Módulo Linux Dedicated Server

cd ~/Unity/6000.0.39f1
wget https://download.unity3d.com/download_unity/15ea7ed0b100/LinuxEditorTargetInstaller/UnitySetup-Linux-Server-Support-for-Editor-6000.0.39f1.tar.xz
tar -xf UnitySetup-Linux-Server-Support-for-Editor-6000.0.39f1.tar.xz
rm UnitySetup-Linux-Server-Support-for-Editor-6000.0.39f1.tar.xz
ls Editor/Data/PlaybackEngines/LinuxStandaloneSupport/Variations | grep -i server
O último comando deve listar pastas com server. Se o wget der 404, confira o nome do arquivo na página https://unity.com/releases/editor/archive (Unity 6000.0.39f1 → Linux).

2.4 Ativar a licença

UNITY=~/Unity/6000.0.39f1/Editor/Unity
xvfb-run -a $UNITY -batchmode -quit -nographics -logFile - -username "SEU_EMAIL_UNITY" -password "SUA_SENHA_UNITY"
Se aparecer "No valid Unity Editor license found" ou erro de ativação (comum com licença Personal via terminal), use o Plano B (1.4). Com licença Pro/Educacional, acrescente -serial XX-XXXX-XXXX-XXXX-XXXX-XXXX.

2.5 Baixar o projeto

cd ~
git clone https://github.com/danielreissss/Projeto-VR.git
cd Projeto-VR
git lfs pull

2.6 Gerar o build do servidor

cd ~/Projeto-VR
xvfb-run -a $UNITY -batchmode -quit -nographics -projectPath . -executeMethod ServerBuild.BuildLinuxServer -logFile build.log
tail -n 20 build.log
ls Builds/LinuxServer

A primeira vez demora (importa o projeto inteiro). Sucesso = [ServerBuild] StandaloneLinux64: Succeeded. Erros:

grep -E "error CS|Build Finished|Exception" build.log

2.7 Liberar a porta

sudo ufw allow 7777/udp
ip -4 addr
Anote os IPs do ip -4 addr. Se o IP que a rede 5G enxerga não for 172.30.22.31, veja o passo 3.3.

2.8 Rodar o servidor

tmux new -s vr
cd ~/Projeto-VR/Builds/LinuxServer
chmod +x ConsultorioServer.x86_64
./ConsultorioServer.x86_64 -logFile -

Pronto quando aparecer: --- LAN: Iniciando como SERVIDOR DEDICADO na porta 7777 ---

AçãoComando
Sair do tmux sem parar o servidorCtrl+B e depois D
Voltar ao servidortmux attach -t vr
Parar o servidorCtrl+C dentro do tmux
Conferir a portass -ulpn | grep 7777

No Plano B, use cd ~/consultorio-build no lugar de cd ~/Projeto-VR/Builds/LinuxServer.

3. Lab — entrar no cenário

3.1 Ligar o Quest

  1. Adaptador USB-C → Ethernet no Quest (de preferência com carga).
  2. Cabo no roteador 5G.
  3. No Quest: Configurações → Wi-Fi → desligar.

3.2 Entrar

Com o servidor rodando: Biblioteca → Fontes desconhecidas → Consultorio VR. O app conecta sozinho. Cada óculos que abrir o app entra na mesma sala.

3.3 Se o IP do servidor for outro

Sem refazer o APK, pelo PC com adb (USB, ou rede com adb connect IP_DO_QUEST:5555):

"NOVO_IP" | Out-File -Encoding ascii server_ip.txt
adb push server_ip.txt /sdcard/Android/data/com.Danie.ConsultorioVR.DriveE/files/server_ip.txt

Para voltar ao IP da cena:

adb shell rm /sdcard/Android/data/com.Danie.ConsultorioVR.DriveE/files/server_ip.txt

3.4 Conferir que o 5G está no caminho

De um PC ligado ao roteador 5G:

tracert 172.30.22.31

Latência abaixo de 1 ms indica rede local (sem 5G no caminho).
